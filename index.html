Concrete technology · SimulinkAcademic

Concrete Mix Design

A MATLAB/Simulink model documenting a concrete mix-design workflow based on ACI 211.1, including input parameters, lookup-table logic, and absolute-volume calculations.

The repository documents its own tables, assumptions, and example scenarios. Independent verification against the governing standard and project materials is still required before design use.

Geotechnical · MATLAB/SimulinkEducational

Soil Classification Models

Two visual Simulink models exploring soil classification under USCS and AASHTO systems, using laboratory parameters such as percent passing sieve No. 200 and Atterberg limits.

The repository describes simplified decision logic and educational scope. The models should not be treated as complete standards-compliant classifiers without further implementation and testing.
